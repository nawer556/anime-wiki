# Anime Wiki｜混合式推薦方法

本頁是可追溯的推薦規則，不是官方排行榜。請搭配 [[推薦新手的動漫]]、[[兩小時內的動畫電影]] 與各個作品頁閱讀。

## 第一步：理解使用者需求

將查詢分為：

- **硬性限制**：只看 TV／只看 Movie、單次可觀看時長上限、排除特定題材、必須獨立觀看等。
- **軟性偏好**：奇幻、戀愛、運動、角色成長、輕鬆／沉重、故事節奏。
- **未知資訊**：未提供時長的作品不能推定通過「90 分鐘內」等限制。

## 第二步：篩選與排序

1. 先依硬性條件排除不合格作品，對缺乏必要資料者標為 `資訊不足`。
2. 再比較 Genres、Themes、Moods、Pacing 的符合程度。
3. 區分 `高度符合`、`部分符合`、`資訊不足`，**不得生成虛構精確百分比**。
4. 盡量從已有 Wiki 中選 1–3 部解釋；引用作品頁及來源 ID。

## 第三步：沒有符合結果

若 0 部作品符合可驗證的硬性條件，觸發 `AUTO_INGEST_REQUIRED`：

1. 使用具備網路存取能力的 Codex 工作階段找新作品，最多搜尋／驗證 2 輪。
2. 同次最多新增 3 部核實合格的新作品；先放暫存區，依來源驗證後再正式寫入。
3. 自動更新作品頁、分類／主題頁、index.md、log.md，通過 Lint 才重新 Query。
4. 若仍找不到，不得偷偷放寬使用者條件；告知資料缺口並停止。

**目前實作範圍**：已建立 `AGENTS.md` 管理 Codex 工作流程；`scripts/query_wiki.py` 仍為離線篩選器，無結果時只回傳 `AUTO_INGEST_REQUIRED`。在有權限的 Codex 工作階段需依規範執行網路搜尋、Ingest、Lint 和重查，這並不是離線 CLI 或 HTML 自動執行的服務。

## 第四步：引用格式

範例：

- 推薦：[[葬送的芙莉蓮]]
- 根據：[[奇幻]]、[[時間與記憶]]
- 來源：`SRC-001` → [原始整理](../../raw/sources/SRC-001.md) → [官方介紹](https://frieren-anime.jp/intro/)
- 注意：「慢節奏」等為編輯性標籤；官方不一定有同等說法。
