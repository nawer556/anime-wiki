# 查詢類型「科幻」的修復與驗證（2026-11-23）

## 錯誤來源

使用者在公開網頁輸入「科幻」後，截圖顯示：
- 原始 Wiki 內無符合該類型的作品。
- AniList API 回傳 HTTP 500。
- Kitsu 備援只有名稱搜尋，不能接手純類型查詢。

## 修正

新增免費 Jikan v4 類型查詢：`GET /v4/anime?genres=24`（科幻）。加入類型篩選、TV／電影篩選、來源驗證、成人內容排除及片長限制。網站類型選單不再侷限於已收錄 Wiki 類型。

## 已執行測試

- `node --test tests/test_anilist_api.cjs`：包含 AniList 500 → Jikan，科幻電影、快取、內容過濾（模擬 API，非真實外部連線）。
- Wiki 來源、Lint、簡報結構檢查：在專案封裝前重新執行。

## 限制

在本執行環境無法確認 Jikan 真實 API 是否可供目前的使用者網路連線。因此本成果不應宣稱「實際線上搜尋已成功」，需由使用者本機開啟 `docs/search.html` 查驗。
