# 2026-11-23 多語／類型搜尋修復執行紀錄

## 原問題（使用者截圖）

- 搜尋「科幻」顯示 0 筆，外部區域長時間停留在「正在透過免費動漫 API 搜尋」。
- 前一版雖然將「科幻」映射為 Sci-Fi，對服務錯誤仍採多輪串接等待；Kitsu 只能查名稱，不適合類型搜尋。
- 中文作品譯名缺少完整對照，不能直接保證在英文索引下找到作品。

## 修改

1. 增加繁體、簡體、英文、日文常用類型詞的轉換；類型查詢直接使用 AniList 的 genres 與 Jikan 的 genre IDs。
2. 新增常見中文動漫譯名對照；未收錄中文名稱嘗試 Wikipedia 跨語言連結。
3. Jikan 和 AniList 並行查詢，並設定逾時；作品名搜尋可再回退 Kitsu。
4. 免費 API 故障時明確標示「離線參考 · 非即時」；僅提供已整理的名稱、形式、類型，避免亂填片長及來源。
5. 更新搜尋頁面提示、避免舊 JavaScript 快取、保存原本 Wiki 和 HTML 簡報。

## 實際執行與檢查

- `node --test tests/test_anilist_api.cjs`：11/11 通過。
- `python scripts/lint_wiki.py`：10 部作品、12 份來源；0 錯誤、0 警告。
- `python scripts/check_sources.py`：12 份不可變來源完整性檢查通過。
- `python scripts/check_slides.py`：10 張投影片、來源對照和 Wiki 快照通過。
- Chromium 瀏覽器模擬三個公開 API 全部失效：搜尋「科幻」出現 12 部清楚標記的離線參考；「命運石之門」、`Steins;Gate`、`シュタインズ・ゲート` 都能顯示相同作品；「戀愛」出現 5 部參考。
- **限制**：沒有取得從此執行環境到 AniList、Jikan、Kitsu 的真實成功回應，因此上述瀏覽器結果不代表線上 API 一定可用；需在使用者電腦實測。
